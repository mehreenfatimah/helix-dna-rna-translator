# Project history

HELIX began as a university bioinformatics-software project and was originally developed as a notebook-hosted Flask application. The archived notebook in `archive/` preserves that implementation.

This portfolio edition refactors the original code into importable/testable Python modules, adds automated tests, organizes sample inputs/outputs, and removes submission-only files. The underlying project idea and major features come from the original coursework; the repository organization and test suite were added later for reproducibility and maintainability.

No claim is made that the later refactor was part of the original graded submission.
